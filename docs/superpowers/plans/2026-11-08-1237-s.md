# 1237: keep `coverage/` when the `Rakefile` is loaded

**Spec:** https://github.com/yegor256/judges/issues/1237

## Global Constraints

- Loading `Rakefile` — including `rake -T` — must not delete `coverage/`.
- `coverage/` is still deleted when the `test` or `features` task runs, before it writes a new report.
- Task names, descriptions, options and `task default:` stay unchanged.
- Rubocop-elegant clean: `# frozen_string_literal: true`, single quotes, 120 columns, LF.

## Review Focus

1. `rake -T` in a directory with `coverage/keep.txt` — the file must survive (the reported bug).
2. `rake test` with a stale `coverage/` — it must be deleted before tests run.
3. `rake features` alone with a stale `coverage/` — it must be deleted before scenarios run.
4. Full `rake` (`clean test features ...`) — `uncover` must run once before `test`; `features` must not wipe the report `test` just wrote.
5. `test/test_rakefile.rb` under both `rake test` and `PICKS=yes ruby test/test_rakefile.rb` — must pass without SimpleCov interference.

## Task 1: move coverage cleanup into the `uncover` prerequisite

**Files:** `Rakefile` (edit), `test/test_rakefile.rb` (new)

**Interfaces:** `task :uncover` (no args); `Rake::TestTask.new(test: :uncover)`; `Cucumber::Rake::Task.new(features: :uncover)`. `uncover` keeps the name used by factbase#1388.

**AC → test:**

| AC (issue) | Test |
|---|---|
| `rake -T` lists tasks without deleting generated reports | `TestRakefile#test_keeps_coverage_when_loaded` |
| cleanup happens when the `test` task runs | `TestRakefile#test_test_cleans_the_coverage` |
| cleanup happens when the `features` task runs | `TestRakefile#test_features_cleans_the_coverage` |

**TDD steps:**

1. RED: add `test/test_rakefile.rb` with the three tests; run `bundle exec ruby -Itest test/test_rakefile.rb` — `test_keeps_coverage_when_loaded` fails on the current `Rakefile` (file gone), the two prerequisite tests fail with `Expected ... to include "uncover"`.
2. GREEN: add `task :uncover` and make `test`/`features` depend on it, removing both inline `Rake::Cleaner.cleanup_files` calls.
3. `bundle exec rake test` and `bundle exec rubocop Rakefile test/test_rakefile.rb` stay green.
